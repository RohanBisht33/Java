<h1>☕ Java Concepts Repository</h1>

<p>
A structured collection of short and clear Java programs covering core fundamentals and Object-Oriented Programming concepts.
</p>

<hr>

<h2>📘 About Java</h2>

<ul>
  <li>Object-Oriented Programming Language</li>
  <li>Platform Independent (Write Once Run Anywhere)</li>
  <li>Strongly Typed Language</li>
  <li>Compiled to Bytecode and executed on JVM</li>
</ul>

<p>
Java programs are compiled using <code>javac</code> and executed using <code>java</code>.
</p>

<hr>

<h2>🧠 Topics Covered</h2>

<ul>
  <li>Variables and Data Types</li>
  <li>Encapsulation</li>
  <li>Inheritance</li>
  <li>Polymorphism</li>
  <li>Abstraction</li>
  <li>Interfaces</li>
</ul>

<hr>

<h2>⚙️ Requirements</h2>

<ul>
  <li>JDK 8 or higher</li>
  <li>VS Code / IntelliJ / Eclipse</li>
  <li>Basic command-line knowledge</li>
</ul>

<hr>

<h2>🛠 Compile and Run</h2>

<p><strong>Compile:</strong></p>

<pre>
javac fileName.java
</pre>

<p><strong>Run:</strong></p>

<pre>
java ClassName
</pre>

<p><strong>Example:</strong></p>

<pre>
javac helloWorld.java
java HelloWorld
</pre>
